# Как поставить аватарку на сайт Roum Bio Maximalist

1. Подготовь квадратную картинку (лучше PNG или WebP).
2. В GitHub открой папку `public`.
3. Нажми **Add file → Upload files**.
4. Загрузи изображение и назови его строго `avatar.png`.
5. Если файл с таким именем уже есть, замени его новым.
6. Нажми **Commit changes**. Cloudflare Pages автоматически пересоберёт сайт.

Сайт уже настроен брать аватар из `/avatar.png`. Если файла пока нет, блок аватарки скрывается автоматически.
